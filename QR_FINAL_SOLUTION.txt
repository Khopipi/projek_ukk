📝 NOTES
───────────────────────────────────────────────────────────────────────────────

WHY BASE64:
- More reliable than file paths in HTML rendering
- DomPDF prefers embedded data URIs
- No file system dependencies
- Works in all browsers and email clients
- No CORS or permission issues

AUTO-GENERATION:
- Controller generates token + QR (primary)
- Component generates token + QR if needed (fallback)
- Never shows placeholder in normal flow
- Idempotent - safe to call multiple times

QR CODE FEATURES:
- Token format: {id}|{timestamp}|{user_id}|{hash}
- Scannable URL: https://domain/pengajuan/ttd?p={token}
- Size: 75x75px with border
- Format: Data URI (base64 encoded PNG)
